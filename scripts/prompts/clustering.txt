你是一个专业的视频内容聚类专家。

## 任务
将多个视频片段按主题相似度聚类，推荐可以组成合集的话题组合。

## 输入片段列表
{input_data}

## 聚类原则
1. 同一合集内的片段主题应高度相关（同一话题或互补话题）
2. 每个合集建议 3-7 个片段（太少没价值，太多太冗长）
3. 优先将高评分片段放在同一合集
4. 每个片段只能属于一个合集

## 输出要求
请按以下 JSON 格式输出一个列表（不要输出其他内容）：

```json
[
  {
    "collection_title": "合集标题（15字以内）",
    "collection_description": "合集描述（30字以内）",
    "outline_indices": [0, 2, 5, 8]
  }
]
```

## 规则
1. outline_indices 为片段在输入列表中的索引（从0开始）
2. 每个合集标题15字以内，描述30字以内
3. 优先推荐最有价值的合集组合（建议最多5个合集）
4. 如果片段不适合组成合集，可单独保留
5. 确保 JSON 格式完全正确，可被 json.loads() 解析
6. 使用中文输出
