# 批量下载弹窗设计方案

> 用于将 ytdownload_ui.py 的批量下载功能集成到 monitor_ui.py

## 入口

`MonitorPage` 标题栏右侧第四个按钮：

```
[全局设置][代理池][⬇ 批量下载][+ 添加账户]
```

按钮样式：`surface2` 背景 + text 色文字，不抢 accent 主按钮视觉。

---

## 弹窗规格

| 属性 | 值 |
|------|-----|
| 类名 | `BatchDownloadDialog` |
| 尺寸 | 640 × 700 px |
| 模式 | `grab_set`（阻塞父窗口交互） |
| 缩放 | 固定，不可调整大小 |

## 默认值来源

| 字段 | 默认值 | 来源 |
|------|--------|------|
| 保存路径 | `config["download_output_path"]` | `monitor/config.json` |
| 视频画质 | 最高画质 | 硬编码 |
| 字幕语言 | `zh-Hans,en` | 硬编码 |
| 下载字幕 | True | 硬编码 |
| 代理池 | （不使用代理池） | `_db.list_proxy_pools()` |
| Cookie | `config["download_cookies_file"]` | `monitor/config.json` |

---

## 字段交互逻辑

### 代理池

- **默认**：「（不使用代理池）」
- **下拉选择** → 选中的池 ID 记录在 dialog 内变量
- **下载时**：选了该池 → 取该池的 `proxy_url` 传给 `batch_download(proxy=proxy_url)`；选「不使用」→ `proxy=None` 直连

### Cookie

- **默认值**：读取 `monitor/config.json` 的 `download_cookies_file` 填入 Entry
- **浏览按钮** → 打开 `filedialog`，选中的文件路径写入 Entry
- **变更后**：点击「开始下载」时，自动将新路径写回 `config["download_cookies_file"]` 并持久化到 `monitor/config.json`
- **下载时**：`batch_download(cookies_file=entry_value)`

---

## 文件上传区行为

- **点击上传区任意位置** → 打开文件选择对话框（根据当前格式过滤 `filetypes`）
  - Excel: `*.xlsx  *.xls`
  - CSV: `*.csv`
  - TXT: `*.txt`
- **选择文件后**：
  1. 调用 `read_urls_from_file()` 解析文件
  2. 下方显示 `✅ 已选择: filename.xlsx     127 条 URL`（绿色）
  3. 数量显示 badge
  4. 解析失败显示 `❌ 解析失败: <错误原因>`（红色）
- **格式切换**：重新选择格式后清空已选文件，重新触发选择

## 进度状态机

```
[空闲] → 点击"开始下载" → [下载中]
  ↑                            │
  │  完成/停止 ← 点击"停止" ─────┘
  ↑
[完成] → 显示汇总结果 → [空闲]（点击确定或X关闭）
```

- **下载中**：`开始下载` → `下载中...`（accent 色降暗 disabled），`取消` → `停止`（warning 色）
- **完成**：按钮恢复，显示汇总行（绿色文字），日志区追加 `========== 下载完成 ==========`，`成功: X  失败: Y`

---

## 进度更新

- **粒度**：视频级（每个视频完成后更新一次），减少 UI 刷新开销
- **进度条**：Canvas 绘制，`accent` 色填充，背景 `surface2`
- **当前视频**：显示截断后的标题（最多 40 字符 + `...`）
- **计数器**：`✓ 已完成: X/Y    ✗ 失败: N    等待中: Z`
- **详情日志**：点击「展开详情 ▼」展开只读 Text 控件，每行格式 `[HH:MM:SS] <状态> 视频标题`

## 与其他系统的对接

| 调用方 | 函数 | 用途 |
|--------|------|------|
| `batch_download()` | `Youtube_Downloader.py` | 核心下载逻辑，支持 aria2/代理/字幕/Cookie |
| `read_urls_from_file()` | `Youtube_Downloader.py` | 解析 URL 文件（Excel/CSV/TXT → URL 列表） |
| `_db.list_proxy_pools()` | `monitor/db.py` | 填充代理池下拉列表 |
| `_load_config()` | `monitor/db.py` | 读取 `download_output_path`、`download_cookies_file` |
| `_save_config()` | `monitor/db.py` | 持久化 Cookie 路径变更 |
