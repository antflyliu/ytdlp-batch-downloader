固定代理工作台 下载出口管理

用节点工作台统一管理下载出口，并把它绑定到账户的自动与批量下载链路中

01 / 06

为什么要做 代理出口隔离

127.0.0.1 → YouTube → HTTP 429
  • 同一 IP 短时间下载过多视频，会触发 429 Too Many Requests
  • 监控任务持续拉起下载，失败往往出现在无人值守时段
  • 失败告警会直接打断通知链路，增加人工排查成本

04 / 06

安全 — 全链路隐私保护

凭证掩码

REST API 返回 http://***@host:port，前端永不展示明文密码

URL 格式验证

后端校验协议 + 主机名，拒绝 htp:/... 等畸形输入

日志脱敏

仅记录 scheme://hostname:port，不含任何认证信息

删除级联

删除固定代理节点时自动清空关联账户引用，防止孤立指针

固定代理节点 已就绪，开始使用

创建代理节点，并在工作台里维护启用状态
