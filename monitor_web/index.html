调度说明
• 进程内只有 一个 Provider Scheduler；各提供方以「定时任务」形式挂在上面，没有单独的「多个 Scheduler」列表。
• 仅 已启用、类型为 list_api / public_feed 且 刷新间隔（分钟）> 0 的提供方会注册定时拉列表；否则启动后也只有每日 cleanup 等任务。
• 重载动态代理任务 只重建任务，不会立即调用外部 API。
• 立即刷新全部列表 API 会立刻执行一次批量 refresh。
• cleanup 会独立记录，不再混入账号监控事件；左侧「最近调度执行」即各任务运行历史。
